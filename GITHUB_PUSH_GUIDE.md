# 🚀 GitHub Push Guide

## 📋 Repository Info

**Repository URL:** `git@github.com:shiyaiteaun/android-app-testing.git`

---

## ✅ Step 1: Check Git Status

```cmd
cd android_app
git status
```

---

## ✅ Step 2: Initialize Git (If Not Already Done)

**If `.git` folder မရှိသေးရင်:**

```cmd
cd android_app
git init
```

---

## ✅ Step 3: Add Remote Repository

**First time setup:**

```cmd
git remote add origin git@github.com:shiyaiteaun/android-app-testing.git
```

**OR if remote already exists, update it:**

```cmd
git remote set-url origin git@github.com:shiyaiteaun/android-app-testing.git
```

**Check remote:**
```cmd
git remote -v
```

---

## ✅ Step 4: Add Files

**All files:**
```cmd
git add .
```

**OR specific files:**
```cmd
git add app/
git add build.gradle
git add settings.gradle
```

---

## ✅ Step 5: Commit Changes

```cmd
git commit -m "Initial commit: Android app with login fix"
```

**OR more descriptive:**
```cmd
git commit -m "Add Android app with login functionality and dashboard"
```

---

## ✅ Step 6: Push to GitHub

### First Time Push:

```cmd
git branch -M main
git push -u origin main
```

### Subsequent Pushes:

```cmd
git push origin main
```

---

## 🔐 SSH Key Setup (If Needed)

**If SSH key မရှိသေးရင်:**

### Step 1: Generate SSH Key

```cmd
ssh-keygen -t ed25519 -C "your_email@example.com"
```

Press Enter to accept default location.

### Step 2: Add SSH Key to GitHub

1. Copy public key:
   ```cmd
   type %USERPROFILE%\.ssh\id_ed25519.pub
   ```

2. GitHub → Settings → SSH and GPG keys → New SSH key
3. Paste the key and save

### Step 3: Test Connection

```cmd
ssh -T git@github.com
```

---

## 🔄 Alternative: Use HTTPS Instead of SSH

**If SSH မသုံးချင်ရင်:**

```cmd
git remote set-url origin https://github.com/shiyaiteaun/android-app-testing.git
```

Then push:
```cmd
git push -u origin main
```

(Username and password/token မေးရင် enter လုပ်ပါ)

## 🚨 Common Issues & Fixes

### Issue 1: "Permission denied (publickey)"

**Fix:** SSH key setup လုပ်ပါ (see above)

**OR** Use HTTPS:
```cmd
git remote set-url origin https://github.com/shiyaiteaun/android-app-testing.git
```

### Issue 2: "Repository not found"

**Fix:** 
- Repository name ကို check လုပ်ပါ
- GitHub account ကို verify လုပ်ပါ
- Repository က public/private ကို check လုပ်ပါ

### Issue 3: "Updates were rejected"

**Fix:**
```cmd
git pull origin main --rebase
git push origin main
```

### Issue 4: "Branch 'main' does not exist"

**Fix:**
```cmd
git branch -M main
git push -u origin main
```
